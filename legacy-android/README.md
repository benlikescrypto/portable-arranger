# Legacy Android ArrangerBox

This is the original Kotlin + Jetpack Compose + Oboe NDK application. It was moved here so Expo Router could own `app/` at the repository root.

Keep this tree until Play Internal publishing scripts are rewired to EAS and hardware behavior is confirmed on the Expo development build. PA4X `.SET` import now lives in the Expo app (`lib/library`).

Build from this directory with the existing Gradle wrapper (`gradlew.bat`) if you need the Compose APK.
